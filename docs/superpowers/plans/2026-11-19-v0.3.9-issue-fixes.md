# v0.3.9 Issue Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the first-run defects reported in #29–#33 and publish a verified v0.3.9 experimental-preview release (tracking #34).

**Architecture:** Keep the existing Rust/GTK/systemd design. Route D-Bus activation through the hardened socket-owning systemd unit; bound emitter on-windows with cooldown and observable transitions; make worker lifetime follow the daemon independently of reference counts. Use ordinary GTK switches as ActionRow suffixes.

**Tech Stack:** Rust, GTK4/libadwaita, systemd/D-Bus, shell packaging tests, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-04-nam-tor-design.md`, specifically §§3.2, 4.10.2, 5.5; issue bodies #29–#33. The owner opted out of further design checkpoints with “just dive in”.

## Global Constraints

- Watchdog: maximum continuous on-time defaults to **2 seconds**; expiry forces off regardless of pipeline state.
- PAM is default-off. Preserve fail-closed auth, socket ACLs, CPU-only inference, and the existing sandbox.
- No model weights, datasets, biometric data, or biometric logs in commits.
- SPDX headers on all Rust files; no production unwrap/expect.
- No host reboot, installed PAM changes, or real biometric capture for this work.
- Stage explicit paths only. Reference existing issues in each fix commit; findings outside scope get issues.
- Keep readiness claims unchanged; unmeasured hardware gates stay unmeasured.

## Review Focus

- Concurrent D-Bus and socket activation must converge on one systemd service without unlinking its live socket.
- Failed emitter-off/re-arm and stalled capture must not silently extend an on-window or return mislabeled authentication frames.
- A worker must exit after abrupt parent death, even when inference or request reads are blocked.
- Programmatic UI rollback must not cause a second privileged request; disabled services must remain untoggleable.
- First install into a running broker must establish identities before a policy reload; no global bus restart.
